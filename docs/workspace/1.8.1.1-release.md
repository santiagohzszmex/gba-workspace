# Workspace 1.8.1.1 Labradorita

Corrección autorizada por Santiago el 21 de noviembre de 2026.

Al asignar Dirección de producción se abre inmediatamente el formulario para definir las acciones delegadas, su motivo y su vigencia, limitada al cargo. La ficha de un cargo existente ofrece «Definir permisos». Ningún permiso se selecciona automáticamente. Se conservan la matriz RBAC, los controles del servidor y la aprobación final exclusiva de Dirección.

No requiere migraciones. Versión nativa 1.8.101. La base pública de descarga 1.5.0 se conserva; los canales de actualización de macOS y Windows reciben el parche.

Validación: flujo local de asignación y segundo paso; pruebas de integrantes, manifiestos y configuración de escritorio; compilación web. Los candidatos nativos se construyen y comprueban en el workflow existente antes de publicar los canales.
